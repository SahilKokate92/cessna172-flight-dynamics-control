# Cessna 172 Flight Dynamics and Control

Development of a nonlinear six-degree-of-freedom (6-DOF) flight dynamics model and flight control system for a Cessna 172 aircraft using MATLAB and Simulink.

## Objectives

- Develop a nonlinear 6-DOF rigid-body aircraft model
- Implement aerodynamic force and moment models using published stability derivatives
- Model aircraft mass properties and geometry
- Implement atmosphere and gravity models
- Determine and verify aircraft trim conditions
- Linearize the nonlinear model
- Analyze aircraft stability modes
- Design flight control systems
- Investigate robustness under parameter uncertainty
